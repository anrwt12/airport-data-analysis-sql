# ✈️ Airport Data Analysis using SQL

## 📌 Project Overview

This project analyzes airport operations and airline performance using SQL and a relational database designed in MySQL. The dataset contains approximately **19,926 flight records** and includes information about airlines, airports, cities, passengers, freight, mail, and flight routes.

The project demonstrates database design, data loading, data analysis, SQL optimization, views, and stored procedures to generate business insights.

---

## 🎯 Objectives

- Design a normalized relational database
- Import and organize airport data
- Analyze airline and airport performance
- Study passenger and freight traffic
- Evaluate airport operations
- Create reusable SQL views and stored procedures
